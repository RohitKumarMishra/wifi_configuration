# Example

Run from the `example/` directory:

```sh
flutter run
```

On a device (not a simulator/emulator without Wi-Fi):

1. Grant location when prompted.
2. Tap **Scan** to list SSIDs (Android nearby scan; iOS configured SSIDs).
3. Enter a passphrase and tap **Connect**.

iOS also needs **Hotspot Configuration** and **Access Wi-Fi Information** in
the Runner target capabilities.
